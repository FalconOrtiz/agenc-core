# AgenC 0.9.2

Swarm agents no longer hit implicit runtime limits, the swarm TUI surface
got a status/transcript polish, and the Bash permission parser now parses
single quotes exactly like the shell it guards.

## Fixes

### Swarm workers run to completion, not to a hidden deadline (#1587)

- Delegated agents and swarm turns no longer carry implicit runtime
  limits: a long-running worker turn is bounded by explicit budgets and
  caller-supplied deadlines only, never by a built-in timer that kills
  legitimate long work mid-flight.
- `Monitor` no longer confuses its bounded foreground yield with the
  monitored process's lifetime. The monitored process has no implicit
  hard timeout and stays available for later `write_stdin` polls until
  it exits or is explicitly stopped; explicit deadlines are honored.
- Full-turn `message.stream`/`message.send` dispatch moved off the
  per-connection FIFO, so daemon control calls issued mid-turn no longer
  wait behind an intentionally unbounded turn.

### Swarm status and transcript polish (#1588)

- New swarm status indicator in the TUI: live worker counts at a glance
  in the workbench and fullscreen layouts.
- Session transcripts render swarm activity more faithfully, pinned by
  new contract tests; TUI startup checks cover the new surface.

### Bash permission parser: shell-quote 1.8.4 → 1.10.0 (#1589)

- shell-quote 1.8.4 treated `\'` inside single-quoted strings as an
  escaped quote; POSIX shells treat a backslash inside single quotes as
  a literal. The divergence let a chained command hide inside what the
  permission splitter saw as one quoted token of an innocuous prefix
  command. 1.10.0 parses single quotes the way the executing shell
  does, so `splitCommandWithOperators` splits compound commands on the
  same boundaries bash uses.

### Coordinator prompt matches assign_task admission (#1589)

- The coordinator system prompt described `assign_task` as targeting a
  running worker; admission actually requires a live, idle, reusable
  descendant. The prompt now states the idle-worker contract, pinned by
  test assertions.

## Upgrading

```sh
agenc update            # standalone installs
npm install -g @tetsuo-ai/agenc@latest   # npm installs
```

Restart the daemon after updating: `agenc daemon restart`.
